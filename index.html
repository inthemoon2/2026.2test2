시작하기 전에 읽어 주세요

  • 면접에서 내 프로젝트와 내 역할을 설명한다고 생각하고 쓰면 돼요. 어려운 문제가 아니에요.
  • [시작하기]를 누르는 순간부터 시간이 흘러요. 새로고침하거나 다시 접속해도 남은 시간이 이어져요.
  • 내용은 20초마다 자동 저장돼요. 한 문항당 500자까지 쓸 수 있고, 최소 글자 수는 없어요.
  • ⚠ 작성 중에 다른 탭·창·프로그램으로 넘어가면(화면 이탈) 1회당 5점이 감점돼요. 검색하거나 다른 화면을 보지 마세요.
  • 시간이 끝나면 자동으로 제출돼요. 끝나기 전에 다 썼다면 직접 제출해도 돼요.
